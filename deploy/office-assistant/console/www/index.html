How to use Athena

Sign in on the right, then type in Ops chat. You talk only to Athena. She asks specialists for you. The left rail is the village map. A green pin means that agent is up.

Athena may ask you to confirm with YES, OK, ya, lanjut, or go before she runs a live inspect, deep read, or other multi-step action. Simple status questions like Lab Docker status or ada yang rusak? use cached snapshots and work without YES. Fleet reports show what each agent can do and which endpoints are up.

  • Athena — orchestrator. Routes questions. Does not restart machines herself.
  • Hephaestus — Lab Docker inspect. Restarts only after you approve.
  • Mnemosyne — vector store (Milvus / Attu). Prod is read-only.
  • Surtr — GPU cluster / MIG. Read-only.
  • Iris — LiteLLM and HTTP routes. Read-only.
  • Argus — metrics and Grafana links. Read-only.
  • Janus — Lab HTTPS path routes (Traefik / office-edge) + TLS leaf status/expiry. He applies routes through the gateway after you approve — not by writing files, and not via Hephaestus. Restarts office-edge only after you approve.
