How to use Athena

Sign in on the right, then type in Ops chat. You talk only to Athena. She asks specialists for you. The left rail is the village map. A green pin means that agent is up.

Agents only read and propose. Anything that changes the lab (a restart, a route change) shows up on the Approvals page, and runs only after a person approves it there.

  • Athena — orchestrator. Answers fleet status and asks the right specialist. Cannot change anything.
  • Hephaestus — Lab Docker and host services. Proposes restarts; they run only after approval.
  • Mnemosyne — vector store (Milvus / Attu) health. Read-only.
  • Surtr — GPU cluster, MIG layout and GPU usage. Read-only.
  • Iris — LiteLLM health and model list. Read-only.
  • Argus — metrics and Grafana links. Read-only.
  • Janus — Lab HTTPS routes (Traefik / office-edge) and TLS expiry. Validates and proposes route changes; they apply only after approval.

Typing "approve" in chat does nothing. Open Approvals, sign in, and click Approve or Reject. Requests expire if nobody decides.
